# x-posts — 20 ready-to-publish posts for X

عشرون منشوراً باللغة الإنجليزية عن برمجة الويب والتطبيقات (فرونت إند + باك إند)،
كل منشور معه كابشن جاهز للنسخ وصورة واحدة أو كاروسيل من عدة صور.

**كل المحتوى في [`CAPTIONS.md`](CAPTIONS.md)** — انسخ الكابشن، وأرفق صور المنشور بالترتيب المذكور.
الصور نفسها في [`images/`](images/).

## قبل النشر: غيّر المعرّف

كل صورة تحمل `@yourhandle` في الأسفل. غيّره مرة واحدة:

```js
// src/theme.mjs
export const BRAND = {
  handle: '@yourhandle',            // ← ضع معرّفك هنا
  tagline: 'web · frontend · backend',
};
```

ثم أعد توليد كل الصور:

```bash
cd x-posts
npm install          # مرة واحدة فقط (playwright-core)
node src/build.mjs   # يعيد بناء الصور الـ58 و CAPTIONS.md
```

لإعادة بناء منشورات محددة فقط:

```bash
node src/build.mjs 4 7 16
```

## تعديل المحتوى

كل النصوص في [`src/posts.mjs`](src/posts.mjs) — كابشن كل منشور وشرائحه في مكان واحد.
عدّل النص، شغّل `node src/build.mjs <رقم المنشور>`، والصورة تتحدث.

أنواع الشرائح المتاحة: `cover` (غلاف)، `code` (كتلة كود)، `duo` / `trio`
(لوحتان أو ثلاث جنباً إلى جنب)، `list` (قائمة مرقّمة)، `rows` (جدول مفتاح/قيمة)،
`flow` (خطوات متسلسلة)، `stat` (رقم كبير).

النص داخل القوائم والجداول يقبل تنسيقاً بسيطاً: `` `code` `` للكود و`*bold*` للتغميق.

### الملاءمة التلقائية

لا حاجة لضبط أحجام الخطوط يدوياً. قبل التقاط كل صورة يشغّل المولّد سكربت داخل
الصفحة يصغّر كتل الكود ثم التصميم كله حتى يدخل المحتوى في اللوحة، ويوحّد حجم الخط
وارتفاع النوافذ بين اللوحات المتجاورة. إن عجز عن ذلك يطبع تحذيراً باسم الشريحة
في نهاية البناء، فلا تمرّ شريحة مقصوصة دون أن تعرف.

## نصائح للنشر

- **انشر الكابشن كما هو.** أول سطرين هما ما يظهر قبل "Show more" — وهما مكتوبان
  ليكونا الخطّاف.
- **الترتيب مهم في الكاروسيل.** الصورة الأولى هي الغلاف وهي ما يقرر إن كان أحد سيتوقف.
- **أضف alt text لكل صورة.** يحسّن الوصول والانتشار معاً، وتويتر يسمح بـ1000 حرف.
- **وزّعها على أسابيع** بدل نشرها دفعة واحدة، وأعد نشر الأفضل أداءً بعد شهرين
  بكابشن مختلف.
- كل كابشن ينتهي بسؤال أو دعوة للحفظ — اترك ذلك، فهو ما يولّد الردود.
